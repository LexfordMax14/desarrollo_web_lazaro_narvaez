# Actividad DCC

Proyecto web simple desarrollado para gestionar el registro y visualización de actividades.

## Contenido del proyecto

- `index.html`: página principal con enlaces a las demás vistas.
- `registro.html`: formulario para registrar actividades.
- `validaciones.js`: validaciones del formulario y guardado de datos en `localStorage`.
- `listado.html`: vista del listado de registros.
- `listado.js`: renderizado, filtro, orden y paginación del listado.
- `estadisticas.html`: página de estadísticas con imágenes de gráficos.
- `styles.css`: estilos básicos compartidos por todas las páginas.

## Funcionalidades principales

- Registro de actividades mediante formulario.
- Validación de campos obligatorios.
- Almacenamiento de registros en `localStorage`.
- Listado de registros en tabla.
- Filtro por cargo.
- Orden por nombre o categoría.
- Paginación simple del listado.
- Visualización de gráficos estáticos en la sección de estadísticas.

## Cómo usar

1. Abrir `index.html` en el navegador.
2. Entrar a `Registro` para ingresar datos.
3. Revisar los datos guardados en `Listado`.
4. Ver los gráficos en `Estadísticas`.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- `localStorage` del navegador
